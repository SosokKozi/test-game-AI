# Чертежи-референсы машин

Сгенерированы `tools/blueprints/make_blueprints.py` по габаритам из `RacingSim/Assets/Resources/Cars/*.json`.
Это **стилизованные** референсы (силуэт и пропорции по мотивам реальных машин), а не заводские чертежи —
детали сверяйте с фотографиями.

В папке каждой машины:

| Файл | Что это |
|---|---|
| `sheet.png` / `sheet.svg` | сводный лист: 4 вида, размеры, характерные черты |
| `side.png` | вид сбоку (слева), 6 × 2 м |
| `top.png` | вид сверху, 6 × 3 м |
| `front.png`, `back.png` | спереди и сзади, 3 × 2 м |

## Как использовать в Blender

Все отдельные виды — **400 пикселей на метр**, без полей.

1. Add → Image → Reference (вид спереди — в окне Front, сбоку — в Right/Left, сверху — в Top).
2. В свойствах изображения (Object Data → Empty) задайте **Size** = ширина вида в метрах:
   `side.png` и `top.png` — **6**, `front.png` и `back.png` — **3**.
3. Положение: центр картинки должен совпасть с центром машины.
   - `side.png`: по горизонтали 0 — середина между осями; земля на 0.2 м выше нижнего края → сдвиньте
     изображение по вертикали на **+0.8 м** (центр картинки на высоте 0.8 м).
   - `top.png`: центр картинки = центр машины.
   - `front.png`, `back.png`: центр по горизонтали — ось машины, по вертикали — на высоте **0.8 м**.
4. Для Unity: в Blender нос машины смотрит в сторону **−Y** (так её видно в окне Front), начало координат —
   на земле посередине между осями, масштаб 1 единица = 1 м, колёса — отдельными объектами.
   Экспорт FBX: Apply Scalings = FBX All, Forward = **−Z Forward**, Up = **Y Up**, включить Apply Transform —
   в Unity нос будет смотреть по +Z, как ждёт игра. Проверьте в Unity и при необходимости поверните корень prefab.

Перегенерировать после правки размеров или формы: `python tools/blueprints/make_blueprints.py`.
