# 3D-модели машин

Построены скриптом `tools/carmodel/build_car_model.py` по чертежам из `Ref/` (4 вида на листе)
и паспортным размерам из `RacingSim/Assets/Resources/Cars/<id>.json`.

| Файл | Что это |
|---|---|
| `RacingSim/Assets/Resources/CarModels/<id>.fbx` | кузов для игры — подхватывается автоматически вместо процедурного |
| `art/models/<id>/<id>.blend` | исходник Blender для ручной доработки |
| `art/models/<id>/<id>_Wheel.fbx` | колесо (шина + диск 10 спиц + гайка), ось X, центр в нуле |
| `art/models/<id>/preview_*.jpg` | превью (сбоку, спереди, сзади, сверху, 3/4) |

## Что внутри FBX

- Объект-корень `<id>` и части: `Body`, `Wing`, `WingEndplateL/R`, `WingMount±`, `Splitter`, `Diffuser`,
  `DiffuserFin*`, `MirrorL/R`, `MirrorArmL/R`. Колёс нет — их рисует физика игры.
- ~180 тыс. треугольников, 6 материалов: `Paint_<id>`, `Glass`, `Carbon`, `Grille`, `Headlight`, `Taillight`.
- Масштаб 1 единица = 1 м, начало координат — на земле посередине между осями.
- Оси: в Blender нос по −Y; экспорт −Z Forward / Y Up с Apply Transform → в Unity нос по +Z.
- UV-развёртка (Smart UV) — для будущих ливрей.

## Как построено и ограничения

Кузов — пересечение силуэтов трёх видов (сбоку × сверху × спереди/сзади) на воксельной сетке 1.7 см,
со сглаживанием; колёсные арки вырезаны по реальным колее и радиусам шин. Материалы назначены по
проекции на чертёж (окна — по виду сбоку, фары/решётки/фонари — по размеченным зонам `tools/carmodel/zones.py`).

Чертежи в `Ref/` не точно в масштабе (по базе машины выходят на 7 % короче и на 10–18 % выше реальных),
поэтому силуэт подогнан под паспорт: база сохранена, свесы растянуты до реальных, высота — до реальной.

Это модель **средней детализации**: силуэт, пропорции, стёкла, фары, крыло, сплиттер — да; мелкие
вогнутости (воздуховоды, жабры, рельеф капота) метод силуэтов не воспроизводит. Их можно доработать
вручную в `.blend` и экспортировать заново (File → Export → FBX с теми же настройками осей).

Пересобрать: `python tools/carmodel/build_car_model.py [id]` (нужны `pip install bpy scikit-image scipy pillow numpy`).
