# Проверка реалистичности

## Эталоны GT3 (ориентиры, зависят от BoP, погоды и шин)

| Показатель | Ориентир |
|---|---|
| 0–100 км/ч | 3.0–3.6 с |
| 0–200 км/ч | 8–10 с |
| Максимальная скорость | 270–290 км/ч (Монца — до ~285) |
| Торможение 200→0 | ~70–80 м, пиковое замедление ~2.0–2.3 g |
| Боковое ускорение | 1.7–2.0 g в быстрых поворотах (с прижимом), ~1.5 g в медленных |
| Монца, круг | ≈ 1:46–1:48 |
| Спа, круг | ≈ 2:16–2:19 |
| Батерст, круг | ≈ 2:00–2:03 |

Трассы в проекте сейчас — приближение (`generate_tracks.py`), поэтому расхождение по кругу в 2–4 % допустимо; после OSM-геометрии ориентиры точнее.

## Автоматические проверки

1. `cd tools/physics-test && dotnet run` — продольная модель на реальных классах `TireModel`, `Drivetrain`, `Wheel`. Сравни с таблицей в README, при изменении обнови таблицу.
2. `python tools/trackgen/generate_tracks.py --plot out.png` — длина, замыкание, `min_gap_m`, профиль высот.
3. При росте проекта — Unity Test Framework (EditMode-тесты для `TireModel`, `Drivetrain`, `LapTimer`, `TrackData.NearestIndex`).

## Тест-драйв в Unity (через MCP)

Сценарии, после каждого — телеметрия (H):
1. Старт с места на полном газу: нет пробуксовки сверх TC, передачи по одной, без «очереди».
2. Прямая Монцы: Vmax в диапазоне, машина стабильна, без раскачки.
3. Торможение перед Rettifilo с 280 км/ч: ABS работает, путь ~130–145 м, нет разворота.
4. Быстрая дуга (Curva Grande / Pouhon): боковые g, баланс (недостаточная/избыточная), нагрузки на колёса.
5. Eau Rouge / Raidillon и The Dipper: сжатие подвески на компрессии, нет «выстрела» вверх, колёса не отрываются без причины.
6. Поребрики: машина подпрыгивает, но не взлетает; трава/гравий тормозят и снижают сцепление.
7. `R` — возврат на трассу без рывков; круг после этого не засчитывается.
8. Полный круг на каждой трассе: время, сектора, хронометраж засчитал круг.

## Телеметрия

Для глубокой настройки — запись в CSV (`Application.persistentDataPath/telemetry/*.csv`) каждые 0.02 с: дистанция, скорость, газ, тормоз, руль, передача, обороты, g, κ/α/нагрузка каждого колеса. Анализ — Python (`pandas` + `matplotlib`) в `tools/telemetry/`: наложение кругов по дистанции, сравнение с ботом/призраком.

## Чек-лист перед коммитом

- [ ] Нет ошибок и новых предупреждений в консоли Unity.
- [ ] `physics-test` в пределах эталонов (если трогали физику/машины).
- [ ] Трассы проходят проверки генератора (если трогали трассы).
- [ ] Ручной круг: меню → старт → круг засчитан.
- [ ] README/CLAUDE.md обновлены, если поменялись управление, структура или цифры.
