# Игровые системы

Сейчас: `Core/RaceSession.cs` (меню, спавн, HUD на IMGUI), `Track/LapTimer.cs` (круги, 3 равных сектора, лучший круг). Режим один — свободная практика.

## Структура при росте

- `Scripts/Race/`: `SessionDirector` (состояния сессии), `RaceRules`, `Standings`, `TrackLimits`, `PitLane`.
- `Scripts/UI/`: экраны и HUD. IMGUI — для отладки/телеметрии; игровое меню и HUD переносить на **UI Toolkit** (или uGUI), когда дизайн устоится.
- `Scripts/Save/`: настройки, рекорды, калибровка руля — JSON в `Application.persistentDataPath`.

## Сессия — машина состояний

`Menu → Loading → Grid/Formation → Countdown → Running → Finished → Results`. Каждое состояние — отдельный класс с `Enter/Update/Exit`. Пауза (`Time.timeScale = 0`) только из `Running`.

## Хронометраж

- Сектора — по реальным границам трасс (добавить в JSON трассы `sectors: [дистанция1, дистанция2]` вместо равных третей).
- Круг засчитывается при пересечении старта после > 90 % дистанции (уже есть); после `R` — круг недействителен (уже есть).
- Дельта к лучшему кругу в реальном времени: сравнение времени на той же дистанции (таблица `bestLapTimeAtDistance` каждые 10 м).

## Правила

- **Лимиты трассы**: все 4 колеса за линией (по смещению от центральной линии > ширина/2 + ~0.3 м) → предупреждение; 3 предупреждения → штраф; заметная выгода по времени → круг аннулируется.
- **Старт**: со стояния (решётка) или с хода (rolling start, как в GT3-сериях), огни 5×красные.
- **Флаги**: жёлтый (авария впереди — сектор), синий (пропусти лидера), чёрный (дисквалификация).
- **Пит-стоп**: ограничение 60/80 км/ч на пит-лейне, остановка в боксе, смена шин / дозаправка — время по формуле, обязательный пит-стоп в длинной гонке.

## Погода и время суток

Положение солнца по времени суток (`Light` вращение + цвет/интенсивность), туман, дождь (частицы + множитель `grip` у `SurfaceInfo` + сохнущая траектория). Зависит от навыка `vehicle-physics` (влияние на шины).

## HUD и меню (что нужно игроку)

Скорость, передача, обороты с лампами переключения, дельта к лучшему кругу, позиция и отставание, круг N/M, карта трассы (из `TrackData.center`), индикаторы ABS/TC/лимитов трассы, сообщения о штрафах. Меню: выбор трассы/машины/режима, настройки помощников, управления, графики, звука, экран результатов.

## Повторы

Запись состояния каждой машины (позиция, вращение, обороты, углы колёс) каждые 0.02 с в кольцевой буфер; проигрывание без физики, с ТВ-камерами. Это же — основа «призрака».
