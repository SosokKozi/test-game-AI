# Машины: данные и модели

## Где лежит

- Характеристики: `RacingSim/Assets/Resources/Cars/<id>.json` → класс `CarSpec` (`Scripts/Vehicle/CarSpec.cs`, все поля с комментариями и единицами СИ).
- Список в меню: `RaceSession.CarIds` + подписи в `DrawMenu` (Toolbar).
- Процедурный кузов: `CarBodyBuilder.cs` (по габаритам, `bodyStyle`: `frontEngine` / `midEngine`).
- Настоящая модель (если есть) подхватывается автоматически: `Assets/Resources/CarModels/<id>.prefab`.

## Добавить новую машину

1. Скопируй ближайший по компоновке JSON (передний/средний двигатель), поменяй `id`, имя, цвета.
2. Заполни данные (порядок важности): масса и развесовка → `cgHeight` → кривая момента и `limiterRpm` → передачи и главная пара → габариты/база/колея/свесы → аэро → подвеска → тормоза.
3. Проверка передач: `Vmax = limiterRpm·2π/60 · R_rear / (ratio6 · finalDrive)` должна дать 275–290 км/ч (GT3 на средних трассах). 1-я передача — ~95–110 км/ч на отсечке.
4. Добавь `id` в `RaceSession.CarIds` и подпись в меню.
5. `cd tools/physics-test && dotnet run` — разгон/торможение в пределах GT3 (см. навык `vehicle-physics`). Затем круг в Unity.

## Откуда брать данные

- Официальные пресс-релизы производителей и страницы гоночных подразделений (масса, мотор, база, габариты).
- Документы BoP (SRO GT World Challenge, IMSA, ADAC GT Masters) — минимальная масса, ограничение мощности/наддува для каждой машины.
- Технические регламенты FIA GT3 — габаритные ограничения, размеры шин (перед 30/68-18, зад 31/71-18).
- Чего нет в открытом доступе (жёсткости, демпферы, аэро-коэффициенты, LSD) — оценивай по физике и проверяй по времени круга; помечай в `notes`, что значения оценочные.
- Не выдумывай точность: лучше «≈» и разумный диапазон, чем фальшивые «точные» числа.

Типичные диапазоны GT3: масса 1230–1350 кг; мощность 500–600 л.с. (по BoP); `cgHeight` 0.38–0.46 м; `dragArea` 0.8–0.95 м²; `downforceArea` 2.2–2.8 м²; `balanceFront` 0.38–0.45; `maxTorqueTotal` тормозов 11–14 кН·м; колёсная частота подвески 100–180 кН/м.

## Настоящая 3D-модель вместо процедурной

1. Источник: своя модель в Blender или скачанная (Sketchfab и т.п.). Проект учебный и некоммерческий, но лицензию модели всё равно отметь в `notes`/README.
2. В Blender: применить масштаб (1 ед. = 1 м), нос по оси **+Z** (Unity), начало координат — на земле посередине между осями, **колёса отделить** (физика рисует свои), сократить полигоны до ~50–150 тыс.
3. Экспорт FBX (Apply Transform, Forward = Z, Up = Y) → `Assets/Models/Cars/<id>/`.
4. В Unity: создать prefab из модели, убрать коллайдеры, сохранить как `Assets/Resources/CarModels/<id>.prefab`.
5. Проверка: Play → машина отображается моделью, колёса (процедурные) стоят в арках. Если не совпадают — правь `trackFront/trackRear`, `wheelbase`, радиусы шин в JSON, а не позицию модели.
6. Свои колёса (диски) — следующий шаг: в `CarBodyBuilder` искать в prefab объекты `Wheel_FL/FR/RL/RR` и использовать их вместо цилиндров.

Большие бинарные файлы (FBX, текстуры) идут через Git LFS — правила уже в `.gitattributes`.
