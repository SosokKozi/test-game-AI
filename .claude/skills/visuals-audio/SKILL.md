# Графика и звук

## Графика

- Сейчас: встроенный рендер, материалы создаются в коде (`Core/MaterialFactory.cs` — сам выбирает `Standard` или `Universal Render Pipeline/Lit`), процедурные текстуры.
- **Переход на URP**: пакет `com.unity.render-pipelines.universal` → создать URP Asset + Renderer → Project Settings → Graphics/Quality. Код материалов и Terrain уже поддерживает URP. Проверить, что нет розовых объектов (TextMesh табличек, Terrain).
- Освещение: солнце + процедурное небо (или HDRI), Volume с постобработкой: Tonemapping ACES, Bloom (слабый), Color Adjustments, Motion Blur (только камера преследования), Vignette.
- Тени: дистанция ~200–300 м, 2–4 каскада. Туман — для глубины на длинных прямых.
- Асфальт: нормал-карта и шероховатость (маркированные тормозные зоны, следы резины на траектории — вершинный цвет или вторая UV).
- Окружение по навыку `track-pipeline`: трибуны, здания боксов, рекламные щиты, барьеры из шин, мосты (Монца — бетонный «Serraglio», Спа — мост на Eau Rouge). Деревья — LOD/импостеры, GPU instancing.
- Камеры: `Core/CameraRig.cs` (преследование, кокпит, капот, ТВ). Для повторов и плавности — Cinemachine 3.

## Звук

- Сейчас: `Vehicle/EngineAudio.cs` — синтез гармоник частоты вспышек в `OnAudioFilterRead` + визг шин. Работает без сэмплов, но звучит «синтетически».
- Улучшение 1 — **гранулярный синтез по сэмплам**: записи двигателя на постоянных оборотах (on-load/off-load, 1000–8000 об/мин шагом 500), кроссфейд по оборотам и нагрузке. Источник — свои записи или свободные библиотеки (проверить лицензию).
- Улучшение 2 — FMOD/Wwise (бесплатно для некоммерческих) — профессиональный путь для двигателей.
- Слои: двигатель (впуск/выпуск отдельно, характер V8/V6/I6), турбо (свист, сброс), трансмиссия (вой прямозубых шестерён — характерно для GT3), переключения (удар/выстрел), шины (визг по combined slip, отдельно продольный/поперечный), ветер (∝ v²), поребрики (стук по `SurfaceInfo.Kerb`), гравий, удары.
- 3D-звук для соперников, допплер, пространственность в кокпите (глуше) и снаружи.

## Производительность

- Цель: стабильные 60+ FPS (на руле лучше 90–144).
- Сначала **Profiler** (Window → Analysis → Profiler), потом оптимизация. Типичные места: число draw calls (деревья, чанки трассы — объединять), тени, физика (500 Гц × машины — для ботов можно 250 Гц, игрока не трогать), построение трассы при загрузке (запекать в ассет).
- Не жертвовать физикой игрока ради FPS.
