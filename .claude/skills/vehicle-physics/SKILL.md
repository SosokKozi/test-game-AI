# Физика автомобиля

Код: `RacingSim/Assets/Scripts/Vehicle/`. Своя модель, **не WheelCollider** — не заменять.

## Порядок шага (VehicleController.FixedUpdate) — не менять без причины

1. `Wheel.UpdateSuspension` ×4 — рейкаст, сжатие, сила пружины/демпфера.
2. `ApplyAntiRoll` — стабилизаторы по осям (разница сжатий × жёсткость).
3. `ApplySteering` — угол колёс с Аккерманом.
4. Педали → `ApplyTractionControl` → `ApplyBrakes` (ABS по каждому колесу).
5. `Drivetrain.Step` — двигатель → сцепление → КПП → LSD → `driveTorque` задним колёсам.
6. `Wheel.UpdateTire` ×4 — динамика скольжения, силы Пасейки, `AddForceAtPosition`, вращение колеса.
7. `ApplyAero` — сопротивление и прижим по осям.

Шаг 0.002 с задаётся в `RaceSession.Start`. Модель шины с длиной релаксации устойчива благодаря **неявной** схеме обновления κ и tanα — при правках сохраняй форму `(x + k·src) / (1 + k·|v|)`.

## Модели и где что лежит

| Что | Файл | Ключевые параметры (JSON машины) |
|---|---|---|
| Шина | `TireModel.cs` | `muLongitudinal/muLateral`, `peakSlipRatio`, `peakSlipAngleDeg`, `shapeC`, `falloffE`, `loadSensitivity`, `relaxationLength` |
| Колесо, подвеска | `Wheel.cs` | `wheelRate`, `bump/reboundDamping`, `travel`, `antiRollRate`, `bumpStopRate` |
| Трансмиссия | `Drivetrain.cs` | `torqueRpm/torqueNm`, `limiterRpm`, `ratios`, `finalDrive`, `shiftTime`, `preload`, `powerRamp`, `coastRamp` |
| Аэро, помощники | `VehicleController.cs` | `dragArea`, `downforceArea`, `balanceFront`, `brakes.biasFront` |

Знаки: κ > 0 — пробуксовка; `tanSlipAngle` хранится как `−vy/|vx|`, сила `fy` направлена по `contactRight`. Положительный угол руля — вправо.

## Диагностика жалоб

| Симптом | Где смотреть первым делом |
|---|---|
| Недостаточная поворачиваемость | ↓ `antiRollRate` спереди / ↑ сзади, ↑ `balanceFront`, `muLateral` передних шин, Аккерман |
| Избыточная, срыв задней оси | ↓ `powerRamp` (LSD), мягче задний стабилизатор, TC, ↓ `coastRamp` при сбросе газа |
| Колебания на месте / дрожание | `MinRelaxSpeed`, `relaxationLength`, демпферы; не повышать жёсткость без проверки dt·k/m |
| Машина «прыгает» / улетает | `compVel` clamp, `bumpStopRate`, коллайдеры трассы (щели между чанками), слой 2 у всех частей машины |
| Не разгоняется со старта | `Drivetrain` автосцепление (`ClutchEngagement`), холостой ход |
| Переключения «очередью» | авто-КПП решает по оборотам колёс + `shiftCooldown` |
| Блокировка колёс | `AbsLevel`, порог `absThreshold`, `biasFront` |

Включай телеметрию (H): нагрузки, κ, угол увода, покрытие каждого колеса — сначала смотри цифры, потом правь.

## Правила изменений

- Любая правка `TireModel`/`Drivetrain`/`Wheel`/JSON машин → `cd tools/physics-test && dotnet run`. Целевые значения GT3: 0–100 ≈ 3.0–3.6 с, 0–200 ≈ 8–10 с, Vmax 270–290 км/ч, 200→0 ≈ 70–80 м, 280→0 ≈ 130–145 м. Сравни с таблицей в README и обнови её.
- Боковую динамику проверяй в Unity (через MCP: Play, телеметрия, круг). Ориентиры времени круга — в навыке `sim-validation`.
- Новый физический эффект — отдельный класс/метод, параметры в `CarSpec` с безопасными значениями по умолчанию (старые JSON должны работать).
- API Unity: без `Rigidbody.velocity/linearVelocity` (используй `GetPointVelocity(worldCenterOfMass)`), без `PhysicMaterial`, без `FindObjectOfType` — проект должен компилироваться и в Unity 2021.3, и в Unity 6.
- Не уменьшать частоту физики ради производительности, пока не измерено, что узкое место именно в ней.

## Дорожная карта эффектов (по порядку пользы)

1. **Температура шин**: ядро/поверхность, нагрев от `|slip|·|F|`, охлаждение от скорости; μ(T) — колокол с оптимумом ~85–100 °C.
2. **Износ шин**: падение μ от накопленной работы скольжения.
3. **Давление шин** → пятно контакта и жёсткость.
4. **Развал/схождение** → поправка к углу увода и μ (camber thrust).
5. **Слипстрим**: снижение `dragArea` и `downforceArea` за машиной впереди (луч назад до 40 м).
6. **Топливо**: масса и центр масс меняются по ходу гонки.
7. **Повреждения**: аэро и подвеска от импульса удара.
8. **Дождь**: множитель `grip` покрытия + аквапланирование по глубине воды.
