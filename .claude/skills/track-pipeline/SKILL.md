# Трассы

## Поток данных

```
tools/trackgen/generate_tracks.py  ─┐   (приближение по сегментам)
tools/trackgen/fetch_osm_track.py  ─┴─► Assets/Resources/Tracks/<id>.json ─► TrackData.Load ─► TrackBuilder.Build (рантайм)
                                         (OSM + SRTM, запускать на ПК с интернетом)
```

Формат JSON: `points` — плоский массив `[x, высота, z, ширина, вираж°, зона_безопасности] × N`, шаг 2 м, X — восток, Z — север, круг замкнут (последняя точка соединяется с первой), точка 0 — стартовая линия. `stride = 6`. Вираж > 0 — правая кромка ниже. Плюс `corners` (имя + дистанция) и `treeDensity`.

## Генератор по сегментам

- Трасса задаётся в `TRACKS` списком `("S", длина)` / `("C", угол°, радиус, "Название")`, угол > 0 — направо; `elevation`, `width`, `bank`, `runoff` — ключевые точки по дистанции реального круга.
- Замыкание — SLSQP: минимально меняет длины прямых и углы (метки `"A"/"B"` и угол `None` — свободнее). Затем сглаживание кривизны (переходные кривые) и масштаб под официальную длину.
- После правок обязательно: `python generate_tracks.py --plot out.png` и проверь в выводе: `length` = официальной, `closure_err` < 10 м, `min_gap_m` больше суммы (ширина/2 + зона безопасности) обеих сторон, `adjusted` — без больших правок; посмотри картинку (форма, порядок поворотов, профиль высот).

## OpenStreetMap + SRTM (точная геометрия)

- `python fetch_osm_track.py <id> [--start lat,lon] [--plot]` — берёт `highway=raceway`, ищет замкнутый контур с длиной, ближайшей к официальной (отсекает пит-лейн и старые конфигурации), высоты OpenTopoData SRTM 30 м со сглаживанием.
- Работает только на машине с интернетом (из облачной сессии Overpass/OpenTopoData недоступны).
- Для новой трассы добавь её в `SITES` (центр, радиус поиска, точка старта) и в `TRACKS` генератора (ширина, вираж, зоны безопасности, названия поворотов).
- Шум SRTM ±5 м: при необходимости увеличь сглаживание или поправь отдельные участки ключевыми точками.

## Построение в Unity (`Scripts/Track/TrackBuilder.cs`)

- Чанки по 120 точек: Road, Lines, KerbRed/KerbWhite, Grass, Gravel, Walls — у каждого `MeshCollider` и `SurfaceInfo` (сцепление, сопротивление, неровность).
- Поребрики там, где |кривизна| > 1/260 м⁻¹ (±16 м), гравий снаружи поворотов с R < 160 м.
- Рельеф: Terrain 513², у трассы на 0.7 м ниже полотна, вдали — IDW высот трассы + шум.
- Порядок обхода треугольников выбирается автоматически по нормали (`MeshBuilder.Quad`).

## Добавить трассу

1. Сегменты + профиль высот в `generate_tracks.py` (или сразу OSM).
2. `id` в `RaceSession.TrackIds` + подпись в меню.
3. Проверка в Unity: старт, полный круг без провалов на стыках чанков, хронометраж засчитывает круг, `R` возвращает на трассу.
4. Сверь время круга с реальным (навык `sim-validation`).

## Дорожная карта

- Пит-лейн (отдельная полилиния, ограничитель скорости, боксы).
- Лимиты трассы: 4 колеса за белой линией → предупреждение/штраф (через `SurfaceInfo` и боковое смещение от центральной линии).
- Тормозные таблички 300/200/100 м, трибуны, здания, маршалы, шины-барьеры.
- LOD/occlusion для деревьев, запекание трассы в ассет в редакторе (ускорит загрузку).
- Нюрбургринг GP/Нордшляйфе, Сузука, Барселона — тем же пайплайном.
